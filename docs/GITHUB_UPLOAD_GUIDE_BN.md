# GitHub-এ Upload Guide

**Repository:** `KrishiBloom-AI`

**Description:** `A beautiful responsive agriculture website with welcome and demo login/signup, fresh market shopping, crop guide, scanner preview and transparent AI research status.`

**Topics:** `agriculture`, `agritech`, `web-development`, `javascript`, `responsive-design`, `github-pages`, `crop-health`, `frontend-portfolio`

**Commit:** `Release complete KrishiBloom AI multi-page website`

1. Final ZIP extract করো।
2. ভিতরের **index.html, app.js, style.css, assets, docs, data**, সব repository root-এ upload করো। ZIP file-টা upload করো না।
3. `Settings → Pages → Deploy from a branch → main → /(root)` দিয়ে Save করো।
4. সাধারণত Live URL হবে `https://esha2310.github.io/KrishiBloom-AI/` (publish হওয়ার পরে)।
5. Links/buttons/mobile views দেখে যাচাই করো।

**মনে রাখবে:** Login demo, payment নেই; Scanner-এ trained disease model নেই।
